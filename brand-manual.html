02 · The mark

Geometry is shared. Treatment is not.

One continuous monogram built on a 96-unit stem. Tiers A and B use the mark directly. Tier C never shows the M on a product tile; the Studio appears only in the endorsement line.

Grid · 1 unit = stem (96)

Solid in tile
Tier B only.

Line + Signal
Tier A, dark grounds.

Line on paper
Tier A, only where the ground is forced light.

  • Stroke weight by size. Line mark: 12 units above 96 px, 22 units (bold) from 24 to 96 px. Below 24 px use the solid mark.
  • Clear space is ½ stem on every side, measured from the outer edge of the mark or tile.
  • Minimum sizes. Tile 24 px / 6 mm. Line mark 24 px. Lockups with text 120 px wide.
  • Tile radius is always 22% of the side. The mark sits at 57% of the tile width, optically centred.
  • Signal dot = ¼ stem, on the baseline, one stem-gap to the right of the line mark.

Tier C09 · Assets · Studio Tools

The developer tools kit.

Every tool gets the same kit, rebuilt in its slot colour. The blueprint grid and corner brackets mark the family; the glyph makes each product unique. Shown here in slot T6 as the reference.

Glyph area · 50%
Product icon · construction1:1 · master 1024 · store 512
  • Tile: 22% radius, gradient at 180° from 700 Field to 900 Floor, blueprint grid of 8×8 cells at 7% white.
  • Glyph: Paper, drawn on a 24-unit grid with a 2-unit stroke, square caps, 45° and 90° angles only, filling 50% of the tile. One idea per glyph. No letters, no M.
  • Corner brackets: top-left and bottom-right, 18% long, inset 11%, same stroke as the glyph. They echo the two arrows of the monogram and mark the tools family.
  • Below 64 px drop the brackets and the grid. Toolbar icons (16 and 32 px) are the glyph alone in 300 Glow on a transparent ground.
  • Never put the Studio M inside a product tile, and never use the safelight gradient for a tool.

11 · Usage

Keep the tiers apart.

Most mistakes come from mixing tiers. Each tier's signature (Signal, tile, product colour) must never appear in another tier.

DO

Tier B: solid white mark inside the safelight tile.

DO

Tier A: line mark on ink, followed by one Signal.

DO

Tier C: slot gradient, glyph, corner brackets.

DON'T

Put the line mark inside the tile.

DON'T

Add the Signal to the tile or to any Tier B or C asset.

DON'T

Use the Studio M as a product glyph.

DON'T

Give a tool a hue from the reserved red zone.

DON'T

Show adjacent slots side by side. Keep them two slots apart.

12 · Tokens

Copy, don't eyeball.

The same values as CSS custom properties, ready for the website and product UIs. A Tier C product overrides only the four --product-* tokens.

/* core · tiers A and B */
:root {
  --safelight:  #8E1519;
  --oxblood:    #3B0306;
  --signal:     #E0262C;  /* Tier A only */
  --ink:        #0E0B0B;
  --charcoal:   #151212;
  --charcoal-2: #1F1A1A;
  --silver:     #8A8A8A;
  --paper:      #FFFFFF;
  --text-2:     #C9C4BF;
  --text-3:     #9A9591;
  --rule:       #3A3333;

  --font-studio: "Archivo";          /* wdth 125 B · 110 C */
  --font-person: "Instrument Serif"; /* roman · A */
  --font-mono:   "JetBrains Mono";
  --font-body:   "Inter";

  --space: 4px;   /* 4 8 12 16 24 32 48 64 96 128 */
  --radius-tile: 22%;
  --radius-ui: 0;
  --ease: cubic-bezier(.2, .7, .2, 1);
}
/* Tier C · product theme (slot T6 shown) */
[data-product] {
  --product-300: #83C1FF; /* glow   · oklch(.80 .13 H) */
  --product-500: #4C94EC; /* accent · oklch(.66 .15 H) */
  --product-700: #225899; /* field  · oklch(.46 .12 H) */
  --product-900: #091F3B; /* floor  · oklch(.24 .06 H) */
  --radius-ui: 2px;
  --product-grad: linear-gradient(180deg,
    var(--product-700), var(--product-900));
}
